Corner Case 工作台

流程 还没有案例 —— 先在 ① 批量生成里跑一批，再点某一行右侧「载入场景」或「CARLA 这条」
加载场景后点「读取关系图」。
俯视图：节点=动态物体，连线=关系（越红=冲突关键度越高），箭头=运动方向
关系边（按冲突关键度排序）
参与者提案（点「用此组合」自动填入「生成 Corner Case」面板）
选择事故类型（多样性的"类型"维度）
每条默认输出两个可播放视频：主车视角（与播放效果一致，不加包围盒/ID）+ 俯视视角(BEV)（上帝视角，看得到谁从哪来）；同一种子结果可复现。
③ 闭环评估（用你们自己的 4DGS 重建渲染）和 ④ CARLA 验证（第三方物理仿真器）是 两条独立的验证通道，都吃同一份事故轨迹：③ 回答"这个视角渲染可不可信、自车按动作推进会怎样"， ④ 回答"在真仿真器里会不会撞、撞得有多严重"。不必先 ③ 再 ④；只关心物理效果可以直接 ④。 推荐用法：③ 快速筛（便宜）→ ④ 复核（有物理/碰撞事件）。
下面这些按钮都是对 当前场景状态 做评估；要对"批量生成的某一条"评估，回 ① 批量生成，点那一行的「载入场景」。
扩散渲染精修（Difix）：把渲染画面精修一遍（独立可用，不必先跑一键自检）
精修前 / 精修后 并排显示；首次会加载扩散模型（较慢）
可信域（novel-view trust）：标定 → 扫描 → 逐帧判定
trust 模型用留出视角的真实误差（PSNR/SSIM/LPIPS）+ coverage 标定；R² 会显示在结果里。
actor 资产库（俯视 3D 会用真模型渲染，不再画方框）
资产库让"每辆车/行人"变成可任意摆位的对象中心 3D 资产。
多视角重建（预算检查 → 后台跑 → 看日志）
实测 24 张图（3 视角×8 帧）可跑；40 张（5 视角×8 帧）在 24GB 卡上 OOM，脚本会提前拦下。
P2/P3：相机 rig 传感器 + 闭环 rollout（越界截断）
rollout = 自车按动作运动 → 逐帧观测 + trust → 越界/碰撞/超帧窗即终止；相对阈值 = × 起始帧预测 SSIM。
P4：导出标准格式（OpenSCENARIO + CommonRoad）
道路/车道是占位（预处理数据没有 roadgraph）；轨迹/尺寸/速度真实；导出后会解析回来逐帧比对。
一键自检 / 渲染精修 A/B（后台任务 + 报告）
difix 未就绪时会被拦下并提示缺哪个权重
一键自检会依次跑：trust 模型 → 可信域 → actor 资产库 → 相机 rig → 闭环 rollout → 导出 → 扩散状态，并写一份总报告。
CARLA 闭环仿真：corner case 场景 → CARLA 里跑（含碰撞事件）→ 出视频 / 看实时画面 / 导出标准 OpenSCENARIO
④ CARLA 闭环仿真：CARLA 本身就是物理闭环仿真器（自车在环、有物理和碰撞）， "闭环"说的就是它；③ 是渲染层的可信度评估（你们 4DGS 渲染出来的画面可不可信）， 不是仿真器，两者互相独立、不分先后。
送场景两种方式：用当前编辑的场景（现场导出）或 从 ① 批量生成里点「CARLA 这条」（直接吃该实例的 world.json，不依赖内存场景，最稳）。
想边看边改就用下面的 仿真引擎：播放/暂停、拖时间轴、选中车辆平移旋转删除、加车、存成新场景。
